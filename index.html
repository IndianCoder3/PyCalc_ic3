A lightweight desktop calculator application built using Python and Tkinter.
Simple. Offline. No distractions.

🧠 What is PyCalc?

PyCalc is a simple desktop calculator designed to demonstrate how real applications can be built and packaged using Python.

It focuses on clarity, usability, and learning — not bloated features or ads.

✨ Features

• Clean Tkinter GUI
• Basic arithmetic operations
• Real-time input display

• Built fully in Python
• No internet required
• Beginner-friendly codebase

• Packaged as a real app
• Linux (.deb) support
• Windows (.exe) support

🎯 Project Goals

• Learn Python GUI development
• Understand event handling
• Design user-friendly layouts

• App packaging & distribution
• Desktop deployment basics
• Cross-platform mindset
